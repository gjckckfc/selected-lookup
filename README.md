# 选中即查 · 英汉词典浮窗

看文档或 PDF 时, 用鼠标左键拖选一段文字, 松手后立刻在光标旁弹出中文释义;
选中的词句会自动沉淀成本地的 Markdown 生词本, 右键还能念出来。

为“读外文材料时随手查词”这一个场景做的, 所以刻意做小: 不装驱动, 不占显存,
常驻内存 50 多 MB。（安装脚本会顺手加开机自启, 不想要就去
「任务管理器 → 启动」里关掉, 或者装的时候加 `--no-autostart`。）

**查词典完全离线**；整句翻译和朗读要联网——翻译用的是**你自己申请的 DeepSeek 密钥**，
朗读的在线语音会把文字发给**微软**。两个功能都可以随时关掉，见下面两节。

## 它长什么样

拖选 `aggregate demand`, 松手后弹出:

```
aggregate demand
[经] 总需求
```

拖选 `inflation`:

```
inflation   /in'fleiʃən/
六级、考研、托福、雅思 · 柯林斯 4 星
n. 胀大, 夸张, 通货膨胀
[化] 充气吹胀; 膨胀
复数 inflations
```

选中词形变化时会给出来源, 例如拖选 `went` 会显示 `go 的过去式`。
整串查不到时(比如 `fiscal multiplier`), 自动退回逐词释义, 并跳过 the / of / is 这类功能词。

## 准备

需要 Python 3.10+（当前环境是 3.14.3）。**不需要安装任何第三方库。**

**词典不用手动准备**：第一次运行的时候程序会自己弹一个窗口，把 52 MB 的词典数据
下下来、校验、建好词形索引，过程中显示进度、速度、还剩多久；失败了能重试。
装完就不再联网查词了。整个过程不用碰命令行。

（词典数据来自开源项目 **ECDICT**，不是本项目编的；出处和许可见文首那张表和
[NOTICE.md](NOTICE.md)。）

如果你想手动来（离线环境、或者想提前备好），也可以：

```powershell
# 1. 下载并校验词典 (约 52 MB, 解包后 126 MB)
python scripts/fetch_dict.py

# 2. 构建词形还原索引 (约 1 秒, 生成 4 MB)
python scripts/build_index.py
```

两条路用的是**同一份实现**（`src/dictpack.py`），不会出现"脚本下好的程序不认"。

词典和索引会下到**用户数据目录**里：

```
%APPDATA%\选中即查\data\         词典和索引（第一次运行时下载）
%APPDATA%\选中即查\settings.json  设置（含 API 密钥）
%APPDATA%\选中即查\vocabulary\    生词本
%APPDATA%\选中即查\logs\          日志
%APPDATA%\选中即查\cache\         翻译缓存 + 语音缓存
```

**为什么要放这儿**：程序以后可能装在 `C:\Program Files`，那里普通程序不能写。
数据放在用户目录，改设置、写生词本才不会静默失败；以后升级或重装程序，
生词本也不会被覆盖。程序目录里只留代码。

（如果你是从旧版升级过来的：程序第一次启动时会自动把老位置的数据**复制**过来，
原文件保留当备份，可以自己确认没问题后再删。词典是只读的，不会复制，直接就地读。）

## 运行

```powershell
python src/main.py
```

或者直接双击 `启动.vbs`（用 pythonw 后台运行, 不弹控制台窗口）。

**重复启动不会开出第二个**：程序同一时间只允许跑一个。你要是又点了一次启动，
它不会变成两个图标、两套钩子，而是把已经在跑的那个的**设置窗口**叫到前面来。

### 建快捷方式 / 开机自启（从源码跑时才需要）

```powershell
python scripts/install_shortcuts.py
```

做三件事，全都只动当前用户、**不需要管理员**：

1. 生成一个绿色圆点的图标
2. 在**桌面**和**开始菜单**各建一个「选中即查」快捷方式
3. 加进**开机自启**（写在 `HKCU\...\Run` 里，所以任务管理器的「启动」页能看到它，也能单独关掉）

想撤销就跑：

```powershell
python scripts/remove_shortcuts.py
```

它只删快捷方式和自启项，**不动你的生词本和设置**。

## 开关（任务栏托盘图标）

启动后任务栏右下角会出现一个圆点，它就是开关:

| 状态 | 图标 | 什么时候 | 行为 |
|---|---|---|---|
| 开启 | 🟢 绿灯 | 只要开着就是绿灯，不看 API | 拖选文字才弹窗 |
| 关闭 | 🟡 黄灯 | 关着，而且 API 已接入 | **什么都不弹**, 连取词都不做 |
| 关闭 + API 未接入 | 🔴 红灯 | 关着，而且密钥/模型没填 | 同样不弹；红色是提醒你翻译还没接上 |

- **左键单击**图标: 立刻切换开关（点一下就亮/灭, 没有任何延迟）
- **右键**图标: 弹出菜单（启用取词 / 自动收录到生词本 / 打开生词本 / 设置 / 退出）
- 鼠标悬停在图标上会显示当前状态

不想被打扰时点一下变成黄灯即可; 关掉的瞬间, 已经排队的查词结果也会一并丢弃,
不会出现"关了还弹一下"。

这三个灯其实只表达两件事：**开着还是关着**。开着永远是绿灯；关掉之后才分颜色——
密钥填好了是黄灯，没填是红灯，提醒你 AI 翻译还没接上。去设置里把密钥补上保存，
红灯当场变黄。鼠标悬停会写清楚当前状态和该做什么。

热键（和托盘等价, 看个人习惯）:

| 热键 | 作用 |
|---|---|
| `Ctrl+Alt+Q` | 退出 |
| `Ctrl+Alt+P` | 切换开关 |

## 设置

### 浮窗什么时候出现、什么时候消失

判定标准只有一条：**现在有没有选中文字**。

| 你的动作 | 结果 |
|---|---|
| 拖选一段文字 | 弹出译文 |
| 双击 / 三击选中一个词 | 弹出译文 |
| 在别处单击一下（取消选中） | 立刻收起 |
| 按 `Esc` | 立刻收起 |
| 选着不动 | 一直留着，超过"自动收起"的时间才收起 |
| 鼠标停在浮窗上 | 不会自动收起 |

浮窗可以**按住拖到任意位置**，也可以**一键复制**（见下）。

右键托盘图标 → **设置**，改完立即生效，自动存进 `settings.json`。
设置窗口**默认置顶**（标题栏右边有「置顶」勾选框可以取消），方便一边看设置一边调试。

### 浮窗上的几个操作

- **悬停高亮**：鼠标移到某个单词块上，那一块整体变色。
- **点击复制**：在高亮状态下点一下，复制这一块（词 + 它的释义）。
- **复制全部**：点右上角的「复制全部」，复制整条词条。
- **右键朗读**：右键点哪一块，就念哪一块（详见下面的「语音朗读」）。

拖动也是按住浮窗走，跟"点击复制"靠位移区分：**松手时位移超过 4 像素算拖动，否则算点击**。

两种结果的复制内容不一样：

```
# 整串命中一个词条 inflation
点单词块      →  inflation  /in'fleiʃən/
                 n. 胀大, 夸张, 通货膨胀
                 [化] 充气吹胀; 膨胀

点复制全部    →  再多带下面两行
                 六级、考研、托福、雅思 · 柯林斯 4 星
                 复数 inflations
```

```
# 整串没命中，逐词拆解 fiscal multiplier
点 fiscal 块  →  fiscal
                 a. 财政的, 国库的
                 [经] 财政上的, 会计的, 国库的

点复制全部    →  原文 + 下面所有单词块
```

拖动时全局钩子不会插手——判定方式是"这次手势的起点落不落在浮窗矩形内"，
落在里面就整段交给浮窗自己处理，不取词、也不收起。

| 项目 | 默认 | 说明 |
|---|---|---|
| 启用取词 | 开 | 关掉后拖选什么都不弹（**在托盘右键菜单里开关**） |
| 拖动判定 | 6 px | 固定值，设置界面不再暴露；要改就编辑 `settings.json` |
| 自动收起 | 5 秒 | 固定值，同上 |
| 启用整句翻译 | 关 | 打开后选中句子会自动翻译 |
| 接口地址 / API 密钥 / 模型名 | — | 你自己的密钥，见下 |

设置面板里只放**需要经常调**的东西：AI 翻译、朗读。取词的判定阈值和停留时间这两个
"装好就不用动"的参数按系统默认跑（6px / 5 秒），想微调直接改 `settings.json`。

## 整句翻译

选中一个句子时，浮窗**顶部给出整句中文译文**（也可以直接点它复制），下面照旧列出逐词释义——
整句意思和生词一次给到。

判断规则：一两个词不翻译（直接走词典），三个词以上或带句末标点的才发请求。

### 怎么把 token 花销压到最低

| 手段 | 效果 |
|---|---|
| **只发原文，不带词典释义** | 实测带词典是 7.6 倍 token |
| **本地缓存** | 同一句只翻一次；反复选中同一段是零成本 |
| **本地分流** | 单词和词组不翻译，直接查词典 |
| **输入截断** | 超过 400 字符截断，防止一次误选烧掉一大笔 |
| **尝试关闭思考模式** | 推理模型的思考 token 同样计费；服务商不接受时会自动回落重试 |
| **temperature = 0 + 限制输出长度** | 不让它自由发挥、长篇大论 |
| **锁死提示词** | "只输出译文"，不加解释、不复述、不加引号 |

### 用你自己的密钥

翻译目前**只接 DeepSeek**。理由很简单：它便宜，而翻译是个很基础的功能，
不值得为它引入更贵的服务。设置 → 整句翻译，填两样：

（DeepSeek 是**第三方**在线服务，本项目只是调用它的接口，跟它没有任何合作关系、
也不代表它——见文首那张表。费用由你在它那边自行结算。）

| 项 | 说明 |
|---|---|
| API 密钥 | 在 platform.deepseek.com 申请 |
| 模型名 | 默认 `deepseek-flash`（便宜档）；`deepseek-v4-pro` 质量更好但贵 4–6 倍 |

接口地址写死在代码里（`src/translate.py` 的 `PROVIDER_BASE`），不开放给用户填。
点「测试连接」可以立刻验证配置。以后要加别家，在同一个文件里加一张
"服务商 → 地址"的表让用户选即可。

### 花多少钱

按"一次翻译 = 输入 100 tokens + 输出 60 tokens"估算，用 `deepseek-flash`：

| 用量 | 花费 |
|---|---|
| 一次 | 约 ¥0.0004 |
| 一天 50 段 | 约 ¥0.02 |
| 一个月 | **约 5 毛** |

DeepSeek 还有**错峰半价**：高峰是工作日北京时间 9:00–12:00 和 14:00–18:00，
其余时间（晚上、周末、节假日）全部半价。读书多半在晚上，正好一直在打折时段。

单价随时会变，以平台官网为准。

### 两个提醒

- **选中的文字会发送给你填写的服务商**，不上传其他任何内容。
- **API 密钥明文存在 `settings.json` 里**，请自行注意这台机器的安全。

**外观不开放设置。** 宽度、高度、圆角、不透明度、悬停变清晰这些都由我们定好，
集中写在 `src/popup.py` 顶部的常量区，要调还是改一处：

| 常量 | 值 | 含义 |
|---|---|---|
| `DEFAULT_WIDTH` | 300 px | 浮窗宽度，固定，不随内容变化 |
| `DEFAULT_MAX_HEIGHT` | 380 px | 浮窗最大高度，装不下就滚 |
| `DEFAULT_RADIUS` | 14 px | 圆角半径 |
| `DEFAULT_OPACITY` | 88% | 不透明度 |
| `DEFAULT_HOVER_OPAQUE` | 开 | 鼠标移上去时变完全不透明 |

理由：浮窗是阅读时的配角，样子和尺寸定好就行，多一个旋钮就多一分"要调"的负担。

### 长文本怎么处理

选中一长段英文时，浮窗**不会把原文原样铺满**：

| 情况 | 表现 |
|---|---|
| 原文不超过两行 | 用小字号完整显示 |
| 原文超过两行 | 只显示前两行 + `…`，下面给一个「展开全文」；点开可以再「收起」 |
| 点原文本身 | 复制整段原文到剪贴板 |
| 内容总高度超过「浮窗最大高度」 | 高度封顶，标题区固定不动，内容区用**鼠标滚轮**滚动 |
| 内容放得下 | 高度按内容收缩，不出现滚动提示 |

**宽度是固定的，高度只封顶不固定。** 这是刻意的：宽度固定让浮窗不管查什么都占同样宽的一条，
不挡阅读；高度如果也固定死，查一个短词也要占满一屏高度，反而更碍事。

命令行参数（一般用不到）:

```powershell
python src/main.py --settings D:\my-settings.json
```

## 生词本

**你选中的每一个词、每一句话，都会自动沉淀成 Markdown 文件**，存在项目里的
`vocabulary/` 文件夹。不用点任何按钮，也没有"保存"这一步。

### 为什么是 Markdown

因为它同时满足两件事：人可以直接读、直接改、直接带走；AI 也能零成本地读懂——
AI 时代，纯文本 + 固定结构比数据库更适合"喂给模型"。而且写这些文件**不联网、
不花 token**，只是往本地追加几行字。

### 目录长什么样

```
vocabulary/
├─ README.md               格式说明（给人和 AI 看）
├─ raw/2026-10-05.md       原稿：按天一个文件，选中即自动追加
└─ curated/                沉淀稿：以后从原稿里提炼，目前还没有
```

- **按天分文件**：一天一个文档，一天的量正好塞得进 AI 的上下文，复习节奏也自然。
- **原稿是事实层**：查到什么写什么，机械化、无损，随时可以重新提炼。
- **沉淀稿是学习层**（后续版本）：由规则或 AI 从原稿里挑出精华、剔除太简单的词。

### 条目长这样

```markdown
## inflation
- type: word
- phonetic: /in'fleiʃən/
- meaning: 胀大, 夸张, 通货膨胀 ｜ [化] 充气吹胀; 膨胀
- forms: 复数 inflations
- tags: 六级、考研、托福、雅思 · 柯林斯 4 星
- first_seen: 2026-10-05 14:22
- last_seen: 2026-10-05 18:03
- lookups: 3
```

同一个词只写一次，之后每次遇到只更新 `last_seen`（最近时间）和 `lookups`（遇到过几次）——
`lookups` 高的就是你最该复习的。句子则记 `translation`（译文）和 `gloss`（逐词释义）。
完整字段说明见 `vocabulary/README.md`。

### 三条防脏门槛

自动收录不等于什么都收。查不到又没有译文的不写；纯中文不写；原文超过 400 字截断。
想临时停掉，右键托盘图标取消勾选「自动收录到生词本」即可。

### 空间和成本

每条约 280 字节。就算一天记 30 条，一年也才 2 MB —— 跟 190 MB 的词典比可以忽略，
而写入过程本身零 token 消耗。

## 语音朗读

**右键点浮窗里的哪一块，电脑就念哪一块**——不用选中、不用切窗口。

| 右键点这里 | 念什么 |
|---|---|
| 词头或单词块 | 那个单词 / 短语 |
| 原文块 | 那段原文（超过 200 字只念前半段） |
| 译文块 | 那句中文译文 |

左键仍然是复制，两边不打架。正在念的那一块会变色，念完自动恢复；
点别的块会立刻打断上一句，浮窗一收起声音就停。

**同一句正在念的时候再点它，不会从头重来**——所以急起来连点几次也不会"念好几遍"；
等它念完之后再点，才会重新念一遍。

### 声音是从哪来的

用的是 **Windows 的神经网络语音**——Ava、Emma、Aria、Guy……也就是 Edge「朗读」
用的那一批，接近真人。**不用 API 密钥、不花一分钱。**

这批语音系统默认只给讲述人用，普通程序拿不到。让普通程序也能用上它，靠的是一个
**在开源社区找到的第三方项目**，不是我们写的：

> **[NaturalVoiceSAPIAdapter](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter)**
> —— 作者 [@gexgd0419](https://github.com/gexgd0419)，MIT 许可。
> 它注册一个 SAPI5 语音引擎，把微软的神经网络语音暴露给所有支持 SAPI 的程序。

**本仓库不包含、也不分发这个适配器**（它需要管理员权限安装、装完不能挪动，只能由用户
自己在系统层面装一次），装不装由你自己决定。它跟我们项目的关系只是：**我们调 SAPI 枚举语音，
它负责让那些语音出现在列表里**——两边的代码没有耦合，所以它就算失效，也只是朗读退回本地语音。
几点说明：

- 它是一个独立的 SAPI5 语音引擎，装到任意**固定**目录（例如 `D:\apps\NaturalVoiceSAPIAdapter`）。
  装完不要挪动或删除；要挪就先卸载再装。
- 装上之后系统语音列表里会多出 19 个英语语音，本程序会自动认出来。
- 它靠从系统文件里取密钥来解锁微软的神经网络语音，属于**绕过微软限制**的灰区做法，
  微软没允许第三方程序这么用；系统大更新后可能失效（重装一次即可）。
- **不装也能用**：程序会自动退回系统自带的本地语音；一个英语语音都没有时，
  朗读功能会自己隐藏。

- 默认英语声音是 **Microsoft Ava Online**（女声、美音），中文是 **Microsoft Xiaoxiao Online**。
- 设置 → 朗读 → **英语声音**：19 个英语语音随便挑。
- 这些语音要**联网**合成（几百毫秒）。**读过的会自动缓存**，同一个词第二次零延迟，
  断网也能重放；断网且没缓存时自动退回系统自带的本地语音，不会没声音。
- 语音引擎**按需启动、闲 5 分钟自动关闭**：朗读时才多出一个后台进程，
  闲下来就还回去，平时常驻内存跟以前一样。

### 想在自己的程序里也用上这套语音？

**这套做法可以整个搬走**，而且不花一分钱——比买云 TTS 便宜，比系统自带的好听得多。
思路一句话：**Windows 里的神经网络语音本来只给讲述人用，但社区里有人写了个适配器
（[NaturalVoiceSAPIAdapter](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter)，
作者 @gexgd0419）把它们暴露成标准 SAPI5 语音，于是任何会调 SAPI 的程序都能挑到它们。**

顺便说清楚：**这个适配器不是本项目的代码**，我们只是"发现并使用"了它。功劳归原作者，
坑也由它承担（见下文的代价）。下面的经验是我们把它接进本程序时踩到的，跟适配器本身的
实现无关。

三步：

**1. 让用户装一次那个适配器**（需要管理员权限——它要往系统注册一个语音引擎）

**2. 枚举语音，按名字挑**

```powershell
Add-Type -AssemblyName System.Speech
(New-Object System.Speech.Synthesis.SpeechSynthesizer).GetInstalledVoices() |
    ForEach-Object { $_.VoiceInfo.Name + ' | ' + $_.VoiceInfo.Culture.Name }
```

名字里带 `Online` 的就是神经网络语音（`Microsoft Ava Online`、`Microsoft Xiaoxiao Online`…）；
带 `Desktop` 的是十几年前的老引擎（Zira、David），念稿感很重。

**3. 合成成 wav，再自己播**

```powershell
$s = New-Object System.Speech.Synthesis.SpeechSynthesizer
$s.SelectVoice('Microsoft Ava Online')
$s.SetOutputToWaveFile('out.wav')
$s.Speak('hello')
```

.NET 里用的是同一套 API（`System.Speech.Synthesis.SpeechSynthesizer`），
PowerShell 只是个免安装的载体。

**几条实战经验（都是我们踩出来的）**

- **按内容哈希缓存 wav**。在线合成一次要 0.3–1.9 秒，缓存命中就是零延迟；同一个词念
  第二遍连合成进程都不用起。
- **合成进程按需起、闲置回收**。常驻一个 PowerShell 大约 75 MB，闲着就还回去。
- **必须做本地兜底**。断网时 `* Online` 会失败，`System.Speech` 里的本地语音还能用，
  别让程序静默没声音。
- **系统默认语音是中文的**，直接念英文是一股中文腔——一定要显式按 `en-*` 挑。
- **别用 `winsound` 去打断正在播的声音**。它的 `SND_PURGE` 在现代 Windows 上不生效，
  表现是"点了新词，旧的那句还在念"。换 MCI（`mciSendStringW`）才有确定的控制权。
- **MCI 的播放设备属于"打开它的那个线程"**，跨线程 `stop` 停不掉。所有播放调用要固定
  在同一个线程里发出去。

**代价要如实告诉用户**：适配器靠从系统文件里取密钥来解锁这批语音，属于**绕过微软限制**
的灰区做法——微软并没有允许第三方程序使用讲述人和 Edge 的语音，系统大更新后可能失效
（重装一次即可）。这批语音也是**联网**合成的，文字会发到微软服务器。

安装需要管理员权限、装完还不能挪动，**所以它只能由用户自己装，不适合被程序静默打包进去**。
这也是本仓库不包含它的原因。

### 点下去就有声音

神经网络语音要联网合成，所以头一次念**一个新词**要等 0.3–1.7 秒。为了不让这个等待
落在你右键的那一刻：

- **鼠标在某个词上停 0.25 秒，它已经在后台把音频合成好了**——等你右键，基本是瞬发
  （实测从 1.7 秒降到 **5 毫秒**）。
- 读过的词有缓存，永远是瞬发。
- **「选中就提前生成语音」默认开启**：浮窗一出现就把当前内容合成好，右键必然瞬发。
  代价是你选中的每个词都会被提前发给微软合成（约 50–150 KB/个）——这点流量很划算，
  所以设置里不再暴露这个开关（真想关，改 `settings.json` 里的 `speak_prewarm`）。

### 调节语速

设置 → 朗读 → **语速**，滑块范围 **-6 ~ +6**，默认「正常」：

| 档位 | 同一句话的时长 |
|---|---|
| 慢 6 档 | 5.76 秒 |
| 慢 3 档 | 4.34 秒 |
| **正常** | **3.48 秒** |
| 快 3 档 | 2.21 秒 |
| 快 6 档 | 1.78 秒 |

大约覆盖 **0.6 倍速 ~ 2 倍速**，初学者放慢、高阶加速都够用；念中文译文时也是这个语速。
改完语速后，第一次听某个词会重新合成一次（0.3–1.7 秒），之后照旧秒出；
调回原来的档位，之前那份缓存还在。

适配器是第三方工具（不是我们写的），它靠从系统里取密钥来解锁这批语音，
所以**将来 Windows 大更新后有可能失效**。真失效了：
重跑一次安装程序即可，或者 `Installer.exe -uninstall` 卸掉，
插件会自动退回系统自带的语音。

### 关于隐私

| 功能 | 会不会把文字发出去 |
|---|---|
| 查词典 | **不会**，完全在本机 |
| 整句翻译 | 会，发给你自己填的翻译服务商 |
| 朗读 | 名字带 `Online` 的是微软服务器的语音，**合成时文字会发给微软**；<br>装在系统里的本地语音则完全离线 |

特别注意：**「选中就提前生成语音」默认开着**，所以你选中的每个词/句都会被提前发给微软
合成一次。不想这样的话，把 `settings.json` 里的 `speak_prewarm` 改成 `false`——
那样只有你右键要听的时候才发。

### 想读中文译文 / 换成更好的声音

- 默认**只读英文**：右键译文块没有反应。设置 → 朗读 → 切成「中英都读」，
  译文就会用中文语音念出来。
- 没装适配器的机器：只能用到系统自带的英语语音（比较有机器味）；
  一个都没有的话这个功能会自己隐藏，设置里会说明，并给一个跳转按钮。

### 关掉它

设置 → 朗读 → 取消「启用右键朗读」。关掉后右键不会有任何反应，
语音引擎也不会启动。

## 工作原理

```
鼠标钩子         取词线程              主线程
(只记录坐标)  →  Ctrl+C + 读剪贴板  →  查词典 → 浮窗
                 还原剪贴板
```

- **触发**: 底层鼠标钩子捕获左键按下/松开, 位移超过阈值才算“拖选”,
  这样单击、双击选词、点空白都不会误弹。
- **取词**: 模拟 `Ctrl+C` 再读剪贴板, 兼容性最好。用
  `GetClipboardSequenceNumber` 判断这次复制是否真的产生了新内容,
  取完把用户原来的剪贴板还回去。
- **查询**: 整串精确命中 → 词形还原兜底 → 逐词拆解, 三级降级。
  实测单次查询 0.06–0.3 ms。
- **显示**: tkinter 无边框置顶小窗, 用 `WS_EX_NOACTIVATE`
  保证不抢焦点, 不影响你正在打字的窗口。圆角走
  `CreateRoundRectRgn` + `SetWindowRgn`, 半透明走
  `SetLayeredWindowAttributes`; 鼠标压上去时自动变完全不透明。
- **开关**: 托盘图标用 `Shell_NotifyIconW` 注册, 图标是运行时手工构造的
  RT_ICON 数据（`CreateIconFromResourceEx`），所以依然零第三方依赖。
- **朗读**: 用 Windows 自带的语音引擎（`System.Speech`）在后台合成成 wav,
  再用系统的 MCI 接口播放（可以精确打断上一句）。合成进程按需拉起、闲 5 分钟回收,
  结果按内容哈希缓存在 `%APPDATA%\选中即查\cache\voice_cache\`, 同一个词/句第二次是零延迟。
- **性能**: 钩子回调里只做算术和投递, 慢活全部丢给取词线程,
  不会拖慢系统鼠标响应。

## 打包发布（开发者）

想发给**没装 Python** 的人：

```powershell
python scripts/build_exe.py
```

一次产出三样东西：

```
dist\选中即查\              程序本体（PyInstaller 的产物）
dist\选中即查-1.0\          发布包：程序 + 安装.bat + 卸载.bat + 说明.txt
dist\选中即查-1.0.zip       直接当 GitHub Release 的附件发出去
```

发到 GitHub Release 时附件名要用**英文**——GitHub 会把附件名里的中文直接吃掉，
`选中即查-1.0.zip` 传上去会变成 `-1.0.zip`。本仓库的 Release 用的是
`selected-lookup-<版本>.zip`。

把压缩包发给别人，对方解压后**双击「安装.bat」**即可。安装会把程序放到
`%LOCALAPPDATA%\Programs\选中即查\`，建好桌面和开始菜单的快捷方式、设好开机自启，
全程不需要管理员权限。不想用了双击「卸载.bat」——**生词本和设置都会留着**。

嫌桌面图标占地方的话，可以不带它装（开始菜单那个仍会建，留着当"后台被杀了
怎么重新打开"的入口）：

```powershell
选中即查.exe --install --no-desktop
```

装到固定位置而不是"就地运行"，是因为对方可能把解压出来的文件夹删掉或挪走，
那样快捷方式就全断了。

版本号写在 `src/appinfo.py`，改完重新打包。它会写进 exe 的文件属性
（右键 → 属性 → 详细信息 里能看到），也显示在托盘右键菜单的「关于」里，
还会出现在发布包的文件名上。

打包要先 `python -m pip install pyinstaller`。它只在**打包这台机器**上用；
用户那边不受影响，运行时依然是零第三方依赖。

用的是"文件夹版"（onedir）不是"单文件版"（onefile）：单文件 exe 每次启动都要先把
几十 MB 解压到临时目录，得等 2–5 秒；这个工具是常驻后台、开机自启的，那几秒天天
都得吃一次。

打包后常驻内存实测 **56 MB**，和源码版（55 MB）几乎一样。

## 已知边界

- 少数程序不支持 `Ctrl+C` 复制选中文字(部分扫描版 PDF、终端、游戏),
  这种情况下不会弹窗。扫描版 PDF 需要 OCR, 属于后续计划。
- 词典查不到专业新词和专有名词时, 会走逐词拆解, 结果仅供参考。
- 逐词拆解最多取 6 个实词。
- 词形索引只覆盖 ECDICT 的 `exchange` 字段, 极少数换形词查不到还原关系。
